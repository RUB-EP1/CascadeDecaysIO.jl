# Physics fixtures

The three reference documents are rewritten for callable format 0.1. They retain
published four-vector intensity checksums from amplitude-serialization revision
16fdcf25fa0a4ffea1f61f8ad4ddcbabef080642, as vendored by CascadeDecaysIO revision
69720159976b91f633aa003565ae37922ebbeedf. MIT, Copyright (c) 2024 Misha Mikhasenko.

The COMPASS fixture contains four distributions. Names containing punctuation were
normalized to identifiers, function-level x removed, and generic expressions given
explicit local arguments. Their mathematical expressions and physical parameters
are unchanged. Obsolete single-function argument-point checks were replaced by
unit tests of the explicit callable interface; the distribution checks remain.
